# Teams index

One line per team, status inline. Sessions read this first and load selectively. Machine config for each
team (tracker, repos, channels, meetings, people's ids) is in `config.json` → `teams[]`; this tree holds
the human context.

Action items are **not** here: they live in `../todos/open.md` tagged `+<team-slug>`. Team work awaiting a
decision lives in each team's `intake.md`.
