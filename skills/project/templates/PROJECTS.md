# Projects index

One line per project, status inline so `done` and `dropped` ones can be skipped unopened. A project
missing from here is lost. Protocol: `rules/projects.md`.

Format: `` - [Title](<slug>/PROJECT.md) — `<status>` `<category>` — <one line> ``

Action items are **not** here: they live in `../todos/open.md` tagged `+<slug>`.
